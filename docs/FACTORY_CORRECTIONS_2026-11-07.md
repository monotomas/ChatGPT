# Gjeldende fabrikkrettelser

Den korrigerte opplastingen gir C7#9 → Half Whole Diminished og C7b13 →
Melodic Minor 5: Mixolydian b6. Opplastingen har 52 rader, 18 640 byte,
SHA-256 `794a9941e128aaa3c1bc6f176c7d76a16e0dfc0344abf5624afac5654d0bb43c`.

Brukeren trakk deretter ønsket om å fjerne C13#9. Siste instruks er å
beholde begge C13#9 og C13add#9 og bruke **Chromatic** som fabrikkvalg
for begge. Foreslått Mixolydian, fargeunntak og tilleggstekst er kansellert.
Vanlig kommentering fra forrige versjon beholdes.

Effektivt oppsett har alle 52 stabile akkord-ID-er og 38 uendrede skalaer.
Kanonisk sortert kompakt ID-til-skala-ID-JSON har SHA-256
`8372f68334a1ed37e09500c0b527151a73fa6c18988fd0a972bf933bc3fd779e`.
Midlertidig 51-implementasjon og fargeunntak er arkivert lokalt som
avbrutte forsøk, ikke aktive krav eller testbevis.
