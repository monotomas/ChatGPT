# 0.4.4: akkordtoner i grunnstilling

Dette kontrollpunktet gjelder rekkefølgen i «Chord tones» i spillevinduet.
G13 skal vises G B D F A C E; omvendinger og faktisk MIDI-oktav skal ikke
endre den harmoniske rekkefølgen. Bare innkommende toneklasser vises.

Alle 52 akkordtyper, 38 skalaer og endelige fabrikkverdier beholdes.
MIDI-prosessering og ruting fra 0.4.3 er uendret. Ferske resultater fra
kjerne-, GUI-, prosessor-, VST3- og Windows-installasjonsprøvene legges
til etter kjøring. Ingen faktisk Live-kjøring påstås fra testvertene.
