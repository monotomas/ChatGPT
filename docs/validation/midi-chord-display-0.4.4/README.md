# 0.4.4: akkordtoner i grunnstilling

Dette kontrollpunktet dokumenterer rekkefølgen i «Chord tones» i spillevinduet.
G13 vises G B D F A C E; omvendinger og faktisk MIDI-oktav endrer ikke
den harmoniske rekkefølgen. Bare innkommende toneklasser vises.

Alle 52 akkordtyper, 38 skalaer og endelige fabrikkverdier beholdes.
MIDI-prosessering og ruting fra 0.4.3 er uendret. Alle fire native grupper
bestod på Linux og Windows. Den eksakte Windows-pakken bestod faktisk
installasjon og er publisert med verifisert HTTP-nedlasting.

- [Windows-resultater og nedlastingslenke](windows/README.md).
- [Linux-resultater og G13-bilde](linux/README.md).

Ingen faktisk Live-kjøring påstås fra testvertene.
