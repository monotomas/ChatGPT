# 0.4.3: retning, anslag, kromatisk gjennomslipp og fire kolonner

Dette kontrollpunktet dokumenterer den faktisk kompilerte rettelsen av
sekvensiell overlapp og ny artikulasjon ved samme måltoner. Begge native
rapporter må bevise legato_directional_ties og same_pitch_rearticulation.
Begge må også bevise unrecognized_chord_chromatic_fallback og
stopped_transport_chromatic_fallback. GUI-prøven dekker de godkjente
14/12/12/14 kolonnene, minste bredde og alle52×38 menybindinger.
Alle fire native testgrupper bestod på Linux og Windows. Windows-pakken
bestod faktisk installasjon og er publisert med verifisert nedlasting.
Se [Windows-resultater og lenke](windows/README.md) og
[Linux-resultater og bilder](linux/README.md). Gamle sammenslåingsforventninger
er ikke bevis for den nye atferden. Ingen faktisk Live-kjøring er utført her.

52 akkordtyper/38 skalaer og de endelige0.4.2-fabrikkvalgene beholdes.
Vertsruting/instrumentrolle endres ikke.
