# Flysnapper MIDI — Ableton load failure under investigation

A user reports that Live12.4.6 lists this package but rejects opening it with “This VST3 plug-in could not be opened.” The cause is not confirmed. This package must not be represented as verified usable in Ableton. Earlier Windows installer and generic VST3-host results remain valid within their stated scope.

The existing artifact is retained unchanged for identification and diagnosis. No replacement binary has been issued. All52 user factory choices remain preserved.
