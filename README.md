# Flysnapper 0.1.0

[Last ned komplett kildepakke](downloads/Flysnapper-0.1.0-Source.zip?raw=1)

Dette er en rutings- og MIDI-prototype med kildekode, byggeskript, tester og norsk veiledning. ZIP-filen inneholder ingen ferdig Windows-binær. Audio-til-MIDI er ennå ikke implementert. Windows/MSVC, Ableton-ruting og fysisk latency gjenstår å verifisere.

Pakk ut hele ZIP-filen, for eksempel til D:\Flysnapper-0.1.0. Kjør BUILD_FLYSNAPPER.bat i den utpakkede mappen. Standardkjøringen bygger og tester uten å installere. Les README.md i pakken for installasjonsvalgene.

SHA256 finnes i downloads/SHA256SUMS.txt.
